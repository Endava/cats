# Check Deleted Resources Not Available

| Item                                            | Description                                                                                                                                                                                                                  |
|:------------------------------------------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **Full Fuzzer Name**                            | CheckDeletedResourcesNotAvailableFuzzer                                                                                                                                                                                      |
| **Log Key**                                     | **CDRNA**                                                                                                                                                                                                                    |
| **Description**                                 | This second-phase fuzzer checks that deleted resources are not available anymore. The expectation is that a successful `DELETE` (`2XX`) will make a subsequent `GET` to the same relative resource URL return `404`, `405`, or `410`. It runs after all first-phase fuzzers for a path complete and again after postponed `HappyPath` `DELETE` requests execute. |
| **Enabled by default?**                         | Yes                                                                                                                                                                                                                                                                                                                                                                                  |
| **Expected result**                             | `404`, `405`, or `410`.                                                                                                                                                                                                                                                                                                                                                              |
| **Fuzzing logic**                               | Iteratively **sends** a `GET` for any successful `DELETE` URL recorded during the current run (preserving the exact deleted path without replacing URL parameters or reference data).                                                                                                                                                                                                |
| **Conditions when this fuzzer will be skipped** | When the HTTP method is not `GET` or no successful `DELETE` was recorded.                                                                                                                                                                                                                                                                                                            |
| **HTTP methods that will be skipped**           | `POST`, `PUT`, `PATCH`, `DELETE`, `HEAD`, `TRACE`.                                                                                                                                                                                                                                                                                                                                   |
| **Reporting**                                   | Reports `success` if response code is `404`, `405`, or `410` and `error` otherwise.                                                                                                                                                                                                                                                                                                  |
